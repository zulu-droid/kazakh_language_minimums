# kazakh_language_minimums
This contains the kazakh_lexical_minimum.csv file that has the minimum number of words for each language level for the KAZTEST. These were extracted using the extract_lexicon.py script from the following sources.

https://oqu.qazcorpus.kz/media/books/Лексикалық_минимум_A1.pdf
https://oqu.qazcorpus.kz/media/books/Лексикалық_минимум_A2.pdf
https://oqu.qazcorpus.kz/media/books/Лексикалық_минимум_B1.pdf
https://oqu.qazcorpus.kz/media/books/Лексикалық_минимум_B2.pdf
https://oqu.qazcorpus.kz/media/books/Лексикалық_минимум_C1.pdf
